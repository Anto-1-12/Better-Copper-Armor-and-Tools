# Better Copper Armor and Tools 
# Ty for the 2M download on Curseforge ❤️

A Minecraft mod that expands the use of copper by adding **armor, tools and more**, while staying close to the vanilla experience.

> Designed as a "vanilla+" mod  
> Compatible with multiple Minecraft versions  
> Works on both client and server  

---

## Features

- Copper Armor set
- Full Copper Tools set
- Balanced progression between stone and iron
- Vanilla-friendly design and recipes
- Regular updates across Minecraft versions

> The goal of this mod is to give **more purpose to copper**, a resource that is underused in vanilla Minecraft.

---

## Compatibility

- Minecraft versions:
  - 1.16 → 1.21+
- Mod loaders:
  - Forge
  - NeoForge

- Environment:
  - Client
  - Server
